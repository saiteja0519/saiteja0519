# Banking Management System

## Description
A Java + MySQL based banking management system implementing core banking operations using JDBC.

## Technologies
- Java
- MySQL
- JDBC
- SQL

## Features
- Create account
- Deposit and withdraw funds
- Balance inquiry
- Database persistence

## Concepts Used
- OOP principles
- JDBC
- SQL queries
- Exception handling

## Use Case
Simulates real-world banking operations for backend system practice.
